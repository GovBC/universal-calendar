# تطبيق التقويم العالمي الشامل على iOS وAndroid

مصدر الموقع الحالي ثابت في `dist/`، وليس مشروع React أو Vite أو Next.js. لا يحتاج نشر الموقع إلى تجميع. ينشئ `npm run build` نسخة أصلية في `.capacitor-web/`، ويضيف إليها جسراً صغيراً للجهاز؛ لا يعدّل الملفات المنشورة في `dist/` ولا عنوان `https://universalcalendar.org`.

## البناء

```sh
npm ci
npm run build
npx cap sync
```

المعرّف في كلا المشروعين هو `org.universalcalendar.app`. افتح `android/` في Android Studio، أو `ios/App/App.xcodeproj` في Xcode. تتضمن `codemagic.yaml` مساري فحص دون مفاتيح توقيع ومساري إصدار موقّع. يستخدم iOS حزم Swift Package Manager، فلا توجد خطوة CocoaPods.

لتفعيل إصدار Android في Codemagic، ارفع مفتاح الرفع باسم مرجعي `universal_calendar_upload` في إعدادات التوقيع. لتفعيل إصدار iOS، ارفع شهادة Apple Distribution وملف provisioning المطابقين للمعرّف في إعدادات Codemagic. يمكن تشغيل مساري الفحص قبل إضافة التوقيع. لا تخزن المفاتيح في Git. يجب زيادة رقم البناء لكل رفع لاحق؛ تستخدم مسارات الإصدار متغير Codemagic `BUILD_NUMBER`.

## سلوك الجهاز

- تبقى واجهة الموقع وصفحاته وملفات الصوت والحسابات نفسها مضمّنة في التطبيق، وتعمل الحسابات المحلية دون اتصال. البيانات السحابية والمنصة الصوتية تحتاج اتصال الإنترنت كما في الموقع.
- يستخدم الموقع داخل التطبيق خدمة Capacitor للموقع الجغرافي عندما يختار المستخدم التحديد، ولا يطلب موقعاً في الخلفية. تعمل الكاميرا والميكروفون لخصائص التوثيق والتسجيل القائمة. يحفظ الإعدادات والتسجيلات محلياً في WebView، وتستخدم مشاركة ملفات التقويم منتقي المشاركة في الجهاز.
- يستخدم زر تنبيهات الخلفية إشعارات الجهاز المحلية بدلاً من Web Push. تُجدَّد المواعيد عند فتح التطبيق أو تغيير الموقع والإعدادات؛ يحجز iOS أقرب ٦٠ إشعاراً وAndroid أقرب ٢٤٠ إشعاراً. يلزم فتح التطبيق دورياً لإضافة المواعيد اللاحقة. قد تؤخر أنظمة توفير الطاقة التنبيه. ملف الصوت المضمّن للإشعارات هو مقتطف مدته ٢٠ ثانية من أذان التطبيق. اختيار تسجيل شخصي لصوت صلاة معينة يعمل أثناء تشغيل الواجهة، ولا يتحول تلقائياً إلى صوت إشعار نظام في الخلفية.
- المشروع السابق `android-app/` محفوظ كما كان، بهوية وتوقيع وآلية منبّه مختلفة. حزمة Capacitor بهوية `org.universalcalendar.app` هي تطبيق جديد بالنسبة إلى نظام التحديث في Android؛ لا تحل تلقائياً محل حزمة سابقة ذات معرّف آخر، ولا تنقل تخزين WebView منها.
- لا يستخدم `server.url`؛ يحمّل التطبيق الملفات المحلية، لذا لا يغير عنوان الموقع المنشور ولا يعتمد تشغيل الواجهة على اتصاله.

بعد تعديل ملفات `dist/`، شغّل `npm run sync` قبل البناء. ولتحديث الأيقونات وشاشة البداية من `dist/icon.svg` شغّل `npm run native:assets` عند الحاجة.
